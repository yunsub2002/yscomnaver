# 트렌드 블로그 도우미

구글 트렌드(대한민국) 인기 검색어를 GitHub Actions 가 자동으로 모아서

- **2시간마다** 실시간 인기 검색어 순위를 갱신하고
- **매일 3편**: 오전 7:23 트렌드 글, 낮 12:23 요일별 생활 테마 글(음식·영화음악·육아·여행·취미살림), 오후 5:23 트렌드 글을 사진과 함께 만듭니다.
- 트렌드 글에서는 사건·사고·재판·정치 키워드를 자동으로 뺍니다. 테마 글 사진은 Pixabay(키 있을 때) 또는 CC0 사진만 씁니다.

아이폰에서 아래 주소를 열고 버튼을 눌러 네이버 블로그 앱에 붙여넣기만 하면 됩니다.

**대시보드:** https://yunsub2002.github.io/yscomnaver/

| 폴더 / 파일 | 역할 |
|---|---|
| `index.html` | 아이폰 대시보드 (사진 저장 · 제목/본문/태그 복사 · 실시간 순위 · 지난 글) |
| `trend_bot/make_post.py` | 트렌드 수집 → 글·사진 만들기 |
| `trend_bot/theme_post.py` · `themes/` | 요일별 생활 테마 글과 원고 50편 |
| `trend_bot/photos.py` | 저작권 걱정 없는 사진 가져오기 (Pixabay / Openverse CC0) |
| `.github/workflows/trend.yml` | 자동 실행 시간표 |
| `data/` | 자동으로 만들어지는 순위·글·사진 (직접 고칠 필요 없음) |

지금 바로 새 글을 만들려면: GitHub → Actions → **트렌드 순위·블로그 글 자동 갱신** → Run workflow (mode = post 트렌드 / theme 테마)
